## 结论（基线，2026-10-27）

- bnb fused 在 M=6 时：gate_up 80.6 GB/s（22% 带宽），q_proj 42.8 GB/s（12%），down 46.6 GB/s（13%）；与 profile 的 30% 同一量级，且对 M 几乎不敏感。
- 按层累加（q + 2×kv + o + gate_up + down）每层 0.55 ms，36 层 ≈ 19.8 ms/步，和 trace 里 22 ms 的 gemm_4bit 一致。
- 同一形状 cuBLAS 读 bf16 权重（字节数 2 倍）达到 70%–80% 带宽，墙钟和 bnb 4-bit 相同：4-bit 在这张卡上只换来显存，没换来速度。
- Triton 版的目标：gate_up M=6 ≤ 0.06 ms（≥ 55% 带宽），即 bnb 的 2.5 倍。
